# Export

NERD can export persisted mutation-count profiles and final probe-timecourse
fits as CSV. Database and project selection follow the same rules as the rest
of the CLI.

## Mutation counts

Export one or more named samples:

```bash
nerd export mut_count sample-a sample-b --output mutation-rates.csv
```

Or export every sample with an ingested mutation-count result:

```bash
nerd export mut_count --all --output mutation-rates.csv
```

The columns are `sample`, `site`, `base`, `valtype`, `mutation_rate`, and
`read_depth`. When a sample has been counted more than once, its latest
ingested run is exported.

## Probe timecourses

Export every final site fit generated by one task:

```bash
nerd export probe_timecourse --task-id 42 --output timecourse-fits.csv
```

You can instead select one or more reaction groups, or all persisted fits:

```bash
nerd export probe_timecourse --rg-id 7 --rg-id 8 --output timecourse-fits.csv
nerd export probe_timecourse --all --output timecourse-fits.csv
```

The output columns are `site`, `base`, `construct`, `temp`, `rep`, `buffer`,
`kobs`, `kobs_err`, `kdeg`, `kdeg_err`, `r2`, and `chisq`. If a task ran
multiple fitting rounds, NERD exports one fit per site and prefers the final
successful constrained round, followed by the global round and then the free
round. Failed per-site fits are omitted rather than emitted as blank rows.

For fits created before task provenance was added, `--task-id` recovers rows
from the task's recorded reaction-group scope when that mapping is
unambiguous. If multiple legacy tasks overlap, use `--rg-id` instead.

Omit `--output` to write CSV directly to standard output.
